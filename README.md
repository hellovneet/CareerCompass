# Career Compass v4

Developer: Vineet Sharma

A polished, trust-first career-direction prototype for students after Class 12.

Design principles:
- Only 3 broad directions are shown to reduce decision overload.
- No fake AI accuracy claims or guaranteed outcomes.
- Matching is explainable.
- Important education facts are explicitly meant to be verified through official sources.
- Privacy-first positioning: the static prototype does not ask for name, phone, email, marks, Aadhaar, etc.
